A program that writes one 236-character rant about a four-minute voice note to `/output/entry.txt`. Someone sent a four-minute voice note to the group chat just to say "yeah sounds good" — four minutes of breathing, a dog, and a microwave before the entire plot twist landed.

## Run it

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere else.
